# 🎮 GameZone Retro

Uma página web simples desenvolvida em HTML puro, apresentando a **GameZone Retro**, uma loja fictícia de jogos e consoles clássicos. 

Este projeto foi construído como um exercício prático focado na criação de páginas bem estruturadas, concisas e funcionais utilizando apenas os recursos nativos do HTML.

---

## 🎯 Objetivo do Projeto

Criar uma Landing Page informativa e organizada para a loja, respeitando a restrição técnica de conter **no máximo 50 linhas de código HTML**.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Sem bibliotecas ou CSS externo)

---

## 📌 Funcionalidades e Elementos Implementados

* **Estrutura básica:** Uso de títulos (`<h1>`, `<h2>`), parágrafos com textos em **negrito** e *itálico*.
* **Navegação:** Link interno (âncora para a seção de preços) e link externo para o Instagram.
* **Mídia:** Imagem temática do universo dos games retrô.
* **Lista sem ordenação:** Relação dos consoles disponíveis (NES, SNES, Sega Genesis, Atari 2600).
* **Tabela de preços:** Exibição organizada com jogos, seus respectivos consoles e valores.
* **Rodapé:** Direitos autorais atualizados.
